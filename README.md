# Wild Seasons 🎯

**Wild Seasons** is a cartoon shooting-gallery game for **LG Smart TVs (webOS)**. Aim with the remote at bears, wolves, boars, foxes, rabbits, ducks, pheasants and stags as you play through spring, summer, autumn and winter. Every hit is harmless slapstick: swirly eyes, dizzy stars and flying feathers.

This repository hosts the game's public website, privacy policy and support. The game's source code is kept separately.

## Need help?

Please **[open a support request](https://github.com/BadRianDev/WildSeasons/issues/new/choose)** and pick the form that fits:

- 🐞 **Bug report:** something isn't working.
- 💡 **Feature idea:** a suggestion for the game.
- ❓ **Question / help:** anything else about the game.

Before you post, please check the [existing issues](https://github.com/BadRianDev/WildSeasons/issues?q=is%3Aissue) in case your question has already been answered.

> Issues are public. Please don't include personal information such as your email address, TV serial number or home address.

Only privacy requests that can't be made publicly should go by email. The address is in the [privacy policy](https://badriandev.github.io/WildSeasons/privacy.html).
